# AI 应用开发指南
本系列文档系统介绍大模型应用开发的核心概念、工具链和最佳实践，帮助开发者从基础 API 调用进阶到复杂的 AI 应用架构。

## 文档目录

### 1. [大模型开发概述](./overview.md)
介绍大模型的基本概念和工程实践：
- **核心概念**：Token、上下文窗口、温度参数、消息角色
- **API 调用**：原生 fetch 方式调用 DeepSeek/OpenAI 兼容接口
- **流式输出**：实现打字机效果的流式响应

### 2. [提示词工程](./prompt.md)
掌握高质量提示词的设计方法：
- **角色设定**：通过 system 消息定义模型身份和输出风格
- **任务描述**：具体、结构化的指令编写技巧
- **输出格式控制**：JSON 结构化输出、withStructuredOutput 方法
- **少样本学习**：通过示例引导模型理解格式要求

### 3. [LangChain.js 基础](./langchain.md)
简化大模型调用的开发框架：
- **模型封装**：ChatOpenAI 统一接口，支持多厂商模型切换
- **调用方式**：invoke、stream、batch、bind 四种模式
- **对话管理**：自动维护多轮对话历史
- **提示词模板**：ChatPromptTemplate 实现可复用的提示词结构

### 4. [LangGraph 工作流](./langgraph.md)
构建复杂 AI 流程的图计算框架：
- **核心概念**：节点（Node）、边（Edge）、状态（State）、条件路由
- **状态管理**：Annotation 定义状态结构和更新规则
- **条件分支**：根据模型输出动态决定执行路径
- **循环控制**：实现需要多轮迭代的复杂任务

### 5. [Function Call 函数调用](./functioncall.md)
让大模型具备调用外部工具的能力：
- **工具定义**：使用 Zod Schema 描述工具参数
- **调用流程**：模型决策 → 代码执行 → 结果回传 → 最终回复
- **多工具协调**：同时绑定多个工具，模型自主选择
- **错误处理**：工具执行失败的容错机制

### 6. [RAG 检索增强生成](./rag.md)
让大模型访问私有知识库：
- **Embedding**：文本向量化和语义相似度计算
- **向量数据库**：Chroma 存储和检索文档向量
- **文档分片**：合理的 Chunk 策略平衡检索精度
- **完整流程**：离线建库 → 在线检索 → 增强生成

### 7. [Agent 智能体](./agent.md)
实现自主规划和工具调用的智能系统：
- **ReAct 模式**：推理（Reasoning）+ 行动（Acting）的循环
- **工具节点**：LangGraph 的 ToolNode 简化工具调用
- **循环控制**：防止无限循环的安全机制
- **自主决策**：模型根据中间结果调整下一步行动

## 技术栈

- **模型接口**：OpenAI 兼容 API（DeepSeek、Qwen、Claude 等）
- **开发框架**：LangChain.js + LangGraph
- **类型安全**：Zod Schema 验证
- **向量存储**：Chroma / 其他向量数据库
- **运行环境**：Node.js 18+
