# 前端面试题精选汇总

为了更好地准备面试并夯实前端基础，我将常见的面试题目按照知识体系进行了分类整理。这些内容涵盖了从基础理论到实战经验的各个维度。

## 目录索引

### 🧱 核心基础
- **[HTML 面试题](/interview/html)**：包含语义化、HTML5 新特性、Web 存储等基础知识。
- **[CSS 面试题](/interview/css)**：涵盖盒模型、布局方案（Flex/Grid）、BFC、CSS3 动画及性能优化。
- **[JavaScript 基础](/interview/jsbasics)**：深入原型链、闭包、作用域、异步编程（Promise/Async）等核心概念。

### 🏗️ 框架实战
- **[Vue 面试汇总](/interview/vue)**：响应式原理、生命周期、虚拟 DOM、Vuex/Pinia 及 Vue3 新特性。
- **[React 面试汇总](/interview/react)**：Fiber 架构、Hooks 原理、组件通信、状态管理及性能优化手段。

### 🌐 网络与安全
- **[HTTP/网络协议](/interview/http)**：TCP/UDP、HTTP 1.1/2.0/3.0、缓存策略及跨域解决方案。
- **[前端安全](/interview/safe)**：XSS、CSRF、点击劫持等常见攻击手段及其防御方案。

### ⚡ 进阶能力
- **[性能优化](/interview/performance)**：加载优化、渲染优化、Webpack 构建优化及监控指标。
- **[编程题/算法](/interview/programming)**：手写 Promise、防抖节流、常用算法题及设计模式。
