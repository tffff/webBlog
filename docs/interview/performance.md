## 前端性能优化有哪些？
一、网络层优化
1、减少http请求
- 合并js/css
- 雪碧图
- 小图转base64
2、cdn加速
- 静态资源走cdn
- 开启http2/3
- 压缩资源gzip

二、资源加载优化
1、代码分割 code splittig
2、tree-shaking
3、压缩资源

👉 面试口语：

- 第一是网络层：我们把静态资源全部放到 CDN，开启了强缓存和协商缓存，同时开启 `HTTP2`，减少请求延迟。

- 第二是资源加载：通过路由懒加载和 Webpack 代码分割减少首屏 JS 体积，配合 `Tree Shaking` 去掉无用代码，并对图片做了压缩和 WebP 处理。

- 第三是渲染优化：首屏使用骨架屏减少白屏感知，长列表使用虚拟列表，避免大量 DOM 渲染导致卡顿。

- 第四是运行时：对滚动、输入等高频事件做了防抖和节流，尽量避免频繁 DOM 操作，减少重排和重绘。

- 第五是体验和监控：我们会用 `Lighthouse` 和 `Web Vitals` 跑性能指标，关注 `FCP`、`LCP` 和 `TTI`，并在上线后持续监控和优化。
