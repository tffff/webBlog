# 欢迎来到我的技术博客

这里是我在前端开发道路上的点滴积累与心得总结。本博客涵盖了从基础开发环境配置到高级架构优化的全方位知识体系，旨在通过系统性的梳理，构建属于自己的知识库。

## 知识板块概览

本博客主要包含以下核心内容：

- **🛠️ 开发基础**：记录常用的插件合集、Nginx 配置、版本控制（SVN/GitLab）以及 macOS/iOS 开发环境的搭建指南。
- **🎨 CSS 艺术**：深入探讨 CSS 布局、Houdini、矩阵变换、剪裁路径（Clip-path）等高级视觉表现技术。
- **核心 JavaScript**：系统整理 JS 基础、原型链、异步处理等核心概念的深度解析。
- **🚀 前端框架**：专注 React 与 Vue 生态，涵盖 React Hooks 深度应用、SSR 服务端渲染及 TypeScript 实战。
- **🏗️ 前端工程化**：Webpack/Rollup 构建工具配置、Jenkins 持续集成、Sonar 代码质量检测及自定义 CLI 开发。
- **⚡ 性能优化**：浏览器渲染机制、Node.js 性能调优及前端性能监控方案。
- **🖥️ 服务器与后端**：Linux 常用命令、HTTP 协议深度解析及 Node.js 后端基础知识。
